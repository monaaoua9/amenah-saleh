# Architecture

```
 producers (gRPC bidi stream, JSON codec)
      |  Batch{producer, events[seq,key,time,value]}
      v
 +-----------+   credits (MaxInflight events, semaphore)
 |  ingest   |<--------------------------------------------+
 +-----+-----+                                             |
       | hash(producer) -> lane                            |
       v                                                   |
 +--------+  +--------+                                    |
 | lane 0 |  | lane 1 |   seq dedup, partition, barrier    |
 +---+----+  +----+---+   fan-out, punctuation fan-out     |
     |  \      /  |                                        |
     |   \    /   |       Hash(key) or RoundRobin          |
     v    v  v    v                                        |
 +------+ +------+ +------+ +------+                       |
 | w0   | | w1   | | w2   | | w3   |  window operator,     |
 +--+---+ +--+---+ +--+---+ +--+---+  watermark, state     |
    \        |        |       /        (credits released   |
     \       |        |      /          after sink accepts)-+
      v      v        v     v
          +---------------+
          |     sink      |  stages output per checkpoint epoch,
          +---------------+  emits only after the checkpoint is durable

 coordinator: Begin(id) -> barrier into every lane -> acks from
 lanes + workers + sink -> _COMPLETE marker -> sink.commit(id)
```

## Pieces

**Ingest / partitioning** (`internal/ingest`, `internal/partition`).
A producer stream is pinned to one lane by hashing its name, so per-producer
order holds and `Seq` dedup is a single map lookup. Lanes route each event to a
worker with `Hash` (FNV-1a, keyed state stays on one worker) or `RoundRobin`
(stateless stages only; it splits keyed windows).

**Event time** (`internal/window`). Tumbling, sliding or session (`Gap`) windows on event time. Sessions merge when an event bridges two of them and fire once the watermark passes last-event + gap; they have no allowed lateness. The
watermark is `max(event time) - Disorder`. A window fires when the watermark
passes its end, stays around for `Lateness` ms and re-fires (`Late: true`) if
stragglers land in it, and anything older than that is counted and dropped.
`AdvanceWatermark` injects a punctuation for idle keys / end of input; workers
apply the minimum across lanes so a quiet lane can't push time past data still
queued on a busy one.

**Backpressure** (`internal/engine`). Two layers. Every channel is bounded, and
on top of that an event-count semaphore caps total in-flight events across the
whole pipeline, which is what actually bounds memory. Credits come back only
after the worker has handed its output to the sink, so a slow sink slows
ingest. `Submit` blocks (the gRPC handler stops reading, HTTP/2 flow control
stalls the client); `TrySubmit` / `-shed` returns `RESOURCE_EXHAUSTED`.

**Checkpoints** (`internal/checkpoint`, `internal/engine/align.go`).
Chandy-Lamport style marker snapshot, in the aligned-barrier form used by
Flink. The coordinator injects a numbered barrier into each lane. Each task
snapshots when it has seen the barrier from *every* upstream, holding back
records from upstreams whose barrier already arrived, so channel state is empty
by construction and nothing needs recording. Snapshots are written
tmp + fsync + rename; a checkpoint only exists once `_COMPLETE` is written.
Last 3 are kept. Profile a running server with `-pprof :6060`.

**Rescaling.** Keys map to one of 128 key groups and a worker owns a range
of them. A checkpoint records the lane/worker counts; on restore each new
worker loads every old worker snapshot and keeps the keys it now owns, and
each producer's last `Seq` moves to the lane its hash selects. Requires a
keyed partitioner (`Hash`); round-robin refuses.

**Exactly-once.** State is restored from the last complete checkpoint, the
producer replays from any point at or before it, and lanes drop `Seq <= last`
per producer. Sink output of an uncommitted epoch is discarded on crash and
regenerated by replay. `TestExactlyOnceAcrossCrash` checks the result is
identical to a run with no crash.

## Known gaps

- Sink output is staged inside the checkpoint and re-sent on restore if the
  `_EMITTED` marker is missing, so a crash never loses an epoch. A crash
  between the emit and the marker re-sends it: at-least-once for that one
  epoch, downstream dedups on (key, window start).
- After a rescale the watermark restarts at the slowest old worker's, so a very
  late event can be accepted that an unscaled run would have dropped.
- `Advance` scans all open windows once per batch; fine up to ~100k open
  windows, after that use a timer heap.
- Producers must send contiguous increasing `Seq` and replay from the last
  acked point; the engine has no source offsets of its own.
